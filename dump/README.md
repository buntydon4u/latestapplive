# Legacy dump

This directory contains files archived while cleaning the current React/Vite application.

- `aspnet/`: original ASP.NET pages and web configuration.
- `php-pages/`: superseded PHP/HTML pages and the old standalone local API.
- `codeigniter-api/`: CodeIgniter API scaffold and its documentation.
- `legacy-assets/`: old server-rendered theme bundles, scripts, fonts, and unused images.
- `migration-docs/`: documentation from the earlier migration phase.
- `mobile-apk/`: former Expo/React Native wrapper and APK/AAB build tooling.
- `misc/`: archives and obsolete project metadata.
- `runtime-logs/`: old local development logs.

Files were moved rather than deleted so they can be restored if needed. The active login background was moved to `public/assets/img/auth-background-image.jpg` to preserve its existing URL.
